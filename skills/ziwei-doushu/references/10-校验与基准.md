# 校验与外部基准

## 一、与 iztro 的逐盘对照（32 盘）

数据：MingLi-Bench 的 `data/fortune_api_results.json`（32 个真实命例，用 iztro 预排盘）。

```bash
gh api repos/DestinyLinker/MingLi-Bench/contents/data/fortune_api_results.json \
  -H "Accept: application/vnd.github.raw" > bench/fortune_api_results.json
python skills/ziwei-doushu/scripts/bench_mingli.py bench/fortune_api_results.json
```

对照项：命宫、身宫、五行局、紫微所在宫、四化星。

**结果：32 / 32 一致**（2026-11-21，修正五虎遁与晚子时口径后）。

修之前 25/32，差异全部集中在两类：

1. **五虎遁宫干错位**：`palace_gan` 用 `branch_index - 2` 直接入模 10，子、丑、亥三宫错一格，
   导致五行局与紫微位置连带出错（7 例中 5 例）。正确做法是 `(start + ((b - 2) % 12)) % 10`。
2. **晚子时口径**：23:00 之后主流软件（iztro 等）按次日排，旧版默认按本日，2 例差异。
   现默认按次日，`--no-late-zi` 可切回。

## 四、与公开项目的关系

- 排盘口径与 `SylarLong/iztro` 默认一致（四化表、亮度表、晚子时、五行局），因此可用其生态数据做交叉验证；
- 断语层与 `Renhuai123/ziwei-doushu` 同源（《天纪》＋《全书》），但本项目只做「可检验的应期」，
  不追求解读文本量；
- 事件评估与模型日志为本项目独有；`DestinyLinker/MingLi-Bench` 的 160 题可作为下一步推理层基线。
