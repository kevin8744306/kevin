# 命相同参：面相与阳宅怎么接进盘

来源：许賀峰《紫微斗数进阶 · 命相与阳宅同参》课件第 156–268 页（面相、命例、同参、阳宅定位）。
这一层不是另一套命理，而是**把盘上的判断缩小、修正、落地**，三条铁律写在最后。

## 一、三才与断法顺序

- 天定其时：盘（本命 → 大限 → 小限／流年）——决定议题与十年背景。
- 地定其势：阳宅（方位、床位、使用方式）——决定同一件事在这个环境里被放大还是被抵消。
- 人定其成：相与行为——决定本人当下的状态与可改的一步。

顺序固定（课件 154、200、210）：

1. 本命标出生年四化所在，定「经常出现什么主题」；
2. 大限重看限宫三方四正，定「哪一段时间重点换了」；
3. 小限／流年定「这一年去查什么」，并注明取年位口径与虚岁；
4. 用面部年位对到同一年龄，核形与色；
5. 用阳宅方位核对同期环境；
6. 收束成一件可核实的事（谁签、谁授权、在哪休养、何时交接）。

## 二、面相（何时用、怎么看）

- 流程：全身成形（木火土金水五形、南人北相）→ 局部（三停、五官、五岳、面部十二宫）→
  察神辨色（气色须分部位、季节、光线）→ 核同期人事。
- 年位：33 岁看眉角、35–40 岁看眉眼（眼神常在这里改判轻重）、40 岁看值年夫妻宫、
  49 岁回述、53–62 岁转疾厄、69 岁看下角。
- 纪律：**形（固定）与色（暂时）分开记**；同一部位的颜色、纹路、形态各说一句，不合并成一句断语。

## 三、同参三条原则（课件原案）

1. **相与盘冲突时收窄，不叠加**：盘上见重，而眼神不凶，原课把「死断」收成口舌与官司是非（课件 215）。
2. **阳宅作第三层修正**：同案再问她住西南角，用「坤」解释为何现相没有盘上那么重（课件 215）。
3. **只讲可核实的事**：订婚未成案，先查对方婚姻的法律状态与承诺时点，不把印堂赤色直接当分手（课件 217）。

## 四、阳宅量法

- 定位：先界定所量空间 → 取图中心点 → 记录北向与测量口径；
- **位置与朝向分开**：床在全屋的位置（中心到床）与床头朝向（床自身轴线）是两件事；
- 连回当时问题：记当时人在哪里休息或工作、用了多久，再判断环境能补充什么（课件 266）。
- 调整：先处理可改的实际卡点（分工、审批、交接）→ 再选可逆的空间调整并记录改动前状态 →
  约定回访，区分「改善了」与「仍卡住」（课件 268）。

## 五、输入要求（缺了就不做，不猜）

| 层 | 需要的数据 | 缺失时 |
| --- | --- | --- |
| 面相 | 正面与侧面照、同期对照、年龄 | 不看相，只做盘；不得凭文字描述断相 |
| 阳宅 | 户型图、坐向、床位与书桌位置、入住时间 | 不判阳宅；不得凭「住西南」这类二手描述定吉凶 |
| 同参 | 一件具体的事（签约、合伙、婚约、就医） | 同参不成立，退回盘面判断 |

## 六、铁律

同参只用于**收窄与修正**既有判断，不单独成断；任何一条相或宅的解释，最后都要落回
「哪一件可核实的事、哪一步可以改」。
