# 校验、已知限制与使用纪律

## 一、已验证的部分

1. **农历换算**：1900–2100 逐日与权威历法数据对齐，0 处偏差（闰月、大小月均含）。
2. **紫微起例**：与《紫微斗数》书内「起紫微帝曜简索表」（PDF 第43页）30 日 × 5 局共 150 格全部吻合。
3. **十四主星与主要辅星**：按书内 017–024 节诸表逐条核对（见 `01-排盘规则.md`）。
4. **实盘对照**：《天纪》紫微19（1961 辛丑年三月初五戌时，阴女，金四局，命宫午坐贪狼，
   身宫在寅）与紫微22（1947 丁亥年六月初四巳时，阴男，金四局，命宫寅坐紫微天府火星）
   两盘，宫位、局数、紫微位置、大限起运与顺逆均一致。
5. **大限顺逆**：阳男阴女顺、阴男阳女逆；起运岁数=局数，与《天纪》案例一致。

## 二、已知限制（要主动向用户说明）

1. **星曜亮度**用通行庙旺表，各派有出入；不同版本可能差一格。
2. **四化表**用《全书》一系；中州派庚干科取天府、壬干科取天府。遇到按流派说明，不混用。
3. **闰月与晚子时**：闰月默认「上半月算本月、下半月算下月」；23:00 之后默认不换日。
   用户若知自己按另一派排过盘，要先对齐口径再比较。
4. **小星与十二神**：已入盘的有六吉六煞、禄存、天马、红鸾天喜、天刑天姚、天哭天虚、龙池凤阁、
   孤辰寡宿、三台八座、恩光天贵、天官天福、天才天寿、台辅封诰，以及长生／博士／岁前／将前四组十二神
   （十二神起例已与《天纪》两盘逐宫核对）。**尚未入盘**：天厨、天巫、天月、阴煞、解神、蜚廉、破碎、月德、
   天伤、天使、旬空、截空、天空；**未做**：斗君与流月／流日、大限与流年四化（依《天纪》星不动之说）。
   这些留作下一增量，勿在分析里编造。
5. **不做流年飞星四化**：依《天纪》「流年在动、星都不动」（上册 第48页），
   只叠流年宫、大限与本命四化。若用户要求飞星派结果，说明本 skill 的口径不同。
6. **不做阳宅化解**：倪海厦的化解还包含阳宅方位，本 skill 只到行为与选择层。

## 三、使用纪律

- 不替用户下医疗、法律、投资结论；涉及时给一句「命理不替代专业判断」。
- 不给「几岁会出事」这类断言；只讲条件与代价，并给可执行的对策。
- 用户问具体人事物（合伙、跳槽、结婚）时，先定**当宫**（交友/官禄/夫妻），再看三方四正与四化，
  不要十二宫通讲一遍。
- 分析语言与用户一致；术语首次出现时用一句话解释。

## 五、应期检验协议（小限 vs 流年、四化哪一层更对应）

问题：小限与流年谁更对应？小限四化（以小限宫干起四化）是否有额外区分力？
这只能靠数据回答，不能靠流派辩论。协议如下，`scripts/eval_timing.py` 已实现。

1. **四个假设**：流年宫三方四正 / 小限宫与对宫 / 流年四化 / 小限四化（小限宫干起）。
2. **判据冻结**：每类事件用同一组星曜与神煞判据（见 `ziwei_eval.py` 的 MARK／SHEN／PALACE_OF），
   只换时间层。判据一旦写下，后续新增案例只跑不改；要改判据就另起一轮并重报。
3. **指标**：事件年在该年 ±5 年窗口内的**分位**（0~1），而不是「命中率」——分位不受事件基准率影响。
4. **样本量**：同一类事件 ≥50 例才有初步区分力，≥150 例才能分辨约 0.1 的分位差；
   单人事件太少，需跨人群合并（同一套判据，不同盘）。
5. **防泄漏**：按人划分；同一人的多个事件不得同时用于「调判据」和「报分位」。
6. **当前状态**：仅 2 例（2006 婚、2010 子），分位均值 小限化 0.80 / 小限 0.75 / 流年 0.65 / 流年化 0.43，
   **仅为方法演示，不构成结论**，不得写进任何分析结论当作依据。

小限四化的起法存在流派差异：本 skill 取「以小限宫宫干（五虎遁）起四化」，
另一派直接沿用流年干四化，两者在 `eval_timing.py` 中分开列为「小限化」与「流年化」，便于对照。
