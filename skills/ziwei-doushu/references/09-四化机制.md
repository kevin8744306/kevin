# 四化机制（参照层）

四化不是星，是「变化的方向」。本文件是**参照**，用来解释盘面、检验假设，
**不进强度评分**（评分规则见 `07-判断模型.md`）。

## 一、四化各自主什么

| 化 | 性质 | 应事形状 | 常见误用 |
| --- | --- | --- | --- |
| 禄 | 得、顺、资源 | 事来得自然，有甜头 | 因顺而懈怠、资源被带走 |
| 权 | 任、势、担当 | 要做主、要出力 | 只看到「有权」看不到「耗神」 |
| 科 | 名、理、规矩 | 讲体面、重过程 | 只有形式没有实权 |
| 忌 | 执、缺口、阻 | 越用力越卡 | 当成灾祸，而不是功课 |

机制上必须三层同时成立：**落宫（事在哪）＋落星（以什么性质）＋时间层（何时引动）**。

## 二、三派用法

### 1. 全书系（集文书局本，本 skill 底本）

- 生年四化定一生四条主线；
- 大限以**大限宫干**起四化，流年以**流年干**起四化，作「十年／当年」的引发；
- 基本不做宫与宫之间的连环飞化。

### 2. 中州派（王亭之）

- 核心是**宫干飞四化**：每宫宫干各飞禄权科忌到别宫，形成连锁；
- **忌入**某宫＝被牵住，**忌冲**对宫＝从对面受损，**禄随忌走**＝资源跟着执念跑；
- 重视**自化**（宫干四化落回本宫），视为该宫自己漏掉或转手；
- 四化表差异：庚干科取**天府**、壬干科取**天府**。
- 风险：链条可任意延长，任何结果都能自圆其说，事后拟合风险最高。

### 3. 倪海厦《天纪》

> 「我们每年是流年在动，星都不动，千万不要受外面今年飞明年飞来飞去那种的影响。」（上册 第48页）

- 生年四化定一生四条线；大限／流年只动宫位，**不另飞四化**；
- 四化落到行为：忌＝该放的不硬撑，禄＝资源往哪使力，权＝敢不敢担，科＝要不要名；
- 反对靠改运商品化解，主张靠选择与行为调整（以果决行）。

## 三、本 skill 的取法

1. 生年四化：主评分，四条线。
2. 大限／小限／流年四化：**参照层**，输出但不计分。
3. 依据：实盘检验显示——事业类事件用流年四化会明显更准（孙女士 2020 创业 0.80→0.95），
   婚姻类几乎无增量（同年离婚 0.20／0.30）。详见 `04-校验与限制.md` 第九节。
4. 流派固定：四化表取《全书》一系；中州派的庚、壬干差异只在对照时注明，不混用。

## 四、叠加应期（参照规则，不进分）

| 叠加 | 含义 |
| --- | --- |
| 生年忌 ＋ 流年踏该宫 | 强触发年（例：男方 2020 离婚，流年夫妻宫踏生年太阴忌） |
| 生年禄 被 流年忌冲 | 得而复失，进账后回吐 |
| 大限忌落宫 → 流年踏同宫 | 十年破口被引爆，这类年最重 |
| 同星被两层同向化（双禄／双忌） | 加强 |
| 同星被两层反向化 | 拉扯：机会来了接不住 |

## 五、写断语时的纪律

1. 先说落宫，再说落星，再说时间层；缺一层就标注「该层未取」。
2. 飞星链条不许在事后拼接；要写就写在事前，并留下可证伪的年份。
3. 四化只给方向，吉凶还要看亮度、煞忌与三方四正；单凭一条四化不断事。
