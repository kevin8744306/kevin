# 判断模型（盘面层，2026-11 版）

目标：把「看盘」拆成可复核的维度，每个维度都有取法、语义与权重，不再靠临场感觉。
面相与阳宅按本版约定**只作对照信息**，不进评分（见 `06-命相同参与阳宅.md`）。

## 二、十二长生：每宫都有的阶段标记

起法：水二/土五起申、木三起亥、金四起巳、火六起寅；阳男阴女顺行，阴男阳女逆行。

| 状态 | 语义 | 计分 |
| --- | --- | --- |
| 长生 | 萌发、起步 | −0.3 |
| 沐浴 | 不稳、易动 | +0.1 |
| 冠带 | 成形、有模样 | −0.2 |
| 临官 | 任事、可担 | −0.4 |
| 帝旺 | 极盛、到顶 | −0.4 |
| 衰 | 由盛转减 | +0.2 |
| 病 | 力弱、需养 | +0.3 |
| 死 | 止住、不动 | +0.3 |
| 墓 | 收藏、入库 | +0.2 |
| 绝 | 断、空 | +0.4 |
| 胎 | 酝酿、未显 | −0.1 |
| 养 | 蓄积、待发 | −0.1 |

**读法纪律**：长生状态说的是「宫气的阶段」，不是人的生死。命宫见「死」不等于短命，
多数应「此人不轻易换轨、认死理」；命宫见「衰」多是「越到后段越要收」，与「帝旺」的「一次到位」相对。

## 三、博士十二神：事件类别标记

| 神 | 语义 | 计分 | 神 | 语义 | 计分 |

| 博士 | 智与专业 | −0.2 | 飞廉 | 口舌与被议 | +0.2 |
| 力士 | 力与执行 | −0.1 | 喜神 | 喜庆 | −0.3 |

岁前（岁建…病符）与将前（将星…亡神）只作**类别**，不进分：官非看官符、贯索、飞廉；
病看病符；丧与意外看丧门、白虎；感情看咸池；损耗看劫煞、大耗、小耗。

## 四、计分与裁决

单宫强度：`Σ(煞 +1.0) + Σ(忌 +1.5) + Σ(禄权科 −0.5) + Σ(吉星 −0.5) + Σ(庙旺 −0.3／陷与不得地 +0.3) + 长生分 + 博士分`

层强度：`层权重 × (1 + 单宫强度)`，负分截断在 −0.55 ~ 1.2。

裁决：
1. 大限压流年；本命压大限；
2. 「命好不如限好」——大限强度明显高于本命时以限为准；
3. 小限只作辅证（本宫与对宫同向）；
4. 十二神只定类别，不改吉凶方向。

## 五、每条断语的输出契约

1. 先写宫、星、亮度；
2. 再写同宫、会照（三方四正）、夹；
3. 再写四化方向；
4. 再写长生与博士（阶段与事类）；
5. 最后落年份与可核实的事。
缺任一层就注明「该层未取」，不得以语气补足。
