# 紫微斗数排盘与推导分析

输入「出生年月日时 + 出生地」，先算出命盘事实，再按《天纪》的方法做推导。
盘面事实由脚本计算，不靠模型心算；分析只解释盘面，不杜撰星曜。

## 一、必须先问清的四项

1. **公历还是农历**：默认公历；用户给农历要明确说明。
2. **出生时间**：尽量精确到分。只知时辰（如"辰时"）也能排，取该时辰中点。
3. **出生地**：用于真太阳时校正，取经度；城市名即可，查 `scripts/cities.py`。
4. **性别**：决定大限顺逆与小限起点。

缺少出生地时按 120°E 处理并在结论中说明；缺时间时不得静默假设正午，先问。

## 二、排盘

```bash
python skills/ziwei-doushu/scripts/ziwei.py --date 1990-05-17 --time 14:30 --city 成都 --gender 男
python skills/ziwei-doushu/scripts/ziwei.py --lunar 1985--6-12 --time 06:05 --city 台北 --gender 女 --year 2026
python skills/ziwei-doushu/scripts/ziwei.py --date 1978-11-03 --hour 3 --city 上海 --gender 男 --json
```

- `--date` 公历；`--lunar` 农历（闰月写负数，如 `2020--4-1`）。
- `--city` 查经度；也可 `--lon 113.3 --tz 8` 直接给。
- `--hour` 只给 0-23 的钟点；`--time` 更精确。
- `--year` 输出该年流年（流年宫、大限、小限）；加 `--month 1-12`（农历月）再输出流月宫。
- `--json` 输出结构化结果，便于二次处理或制图。
- `--late-zi` 把 23:00 之后算作次日（默认不换日，只取子时）。

脚本只依赖 Python 标准库，Win/macOS/Linux 均可直接运行。

## 三、真太阳时的处理

排盘用**真太阳时**：`真太阳时 = 当地标准时 + (经度 − 时区中央经线)×4 分钟 + 均时差`。
脚本已算好并打印校正值。中国全境用 +8 时区，西部地区经度校正可达 −50 分钟以上，
出生在成都、昆明、乌鲁木齐、拉萨等地时，**时辰常常会变**，这一步不能省。
新疆、西藏若用北京时间记录，尤其要复核。

## 四、解读的顺序（按《天纪》的讲法）

1. **先看紫微星在哪一宫**，再看命宫落哪一宫——同一张紫微位置只有十二种基本盘型。
2. **命宫主星定性格与用力方向**；命宫无主星时借对宫，说明"随环境塑形"。
3. **三方四正**（命、官禄、财帛、迁移，即命宫的三合宫与对宫）看这一生的资源与舞台。
4. **生年四化**（禄权科忌）落宫是本命最重的四条线：禄=资源、权=担纲、科=名声、忌=执念与消耗。
5. **大限**看十年主调、**流年**看当年触发，两者都要看**三方四正**；**小限**只看本宫与对宫，
   作辅证。四层权重：本命 1.0 ＞ 大限 0.6 ＞ 流年 0.35 ＞ 小限 0.15；
   大限压流年，本命压大限，但「命好不如限好」时以限为准（脚本已按上下限合成强度比较）。
6. 结论用"倾向"而非"注定"，最后一定要落到**可做的事**上（见下）。

## 五、以果决行：分析的落点

《天纪》讲算命是"以果决行"——先问要什么结果，再决定行为，而不是纠缠原因，
也不靠改运商品化解。所以每份分析最后给出 2-4 条**行为层**的建议：
把资源投在禄权科所在的宫位，把忌所在宫位的执念换成方法，忌星所在的领域不硬撑。

## 六、必须说明的限制

- 星曜庙旺、四化表、闰月与子时处理各派有别，本 skill 用集文书局《紫微斗数》与
  《紫微斗数全书》一系（详见 `references/01-排盘规则.md`），遇到流派差异要讲明。
- 命理属传统推演，不替代医疗、法律、投资等专业判断；涉及时明确提示。
- 分析不得编造盘面不存在的星曜或宫位；不确定就说不确定。

## 七、命相同参（可选，需额外输入）

按黑白书院《紫微斗数进阶·命相与阳宅同参》的次序，盘只定议题与年份，相与宅用来收窄：

1. 盘定年（本命 → 大限 → 小限／流年）；
2. 面相年位对同一岁数（33 眉角、35–40 眉眼、40 夫妻、53–62 疾厄、69 下角）；
3. 阳宅方位与使用方式核对同期环境；
4. 收束成一件可核实的事。

没有照片就不看相，没有户型图与坐向就不判宅——**不凭文字描述编相、编宅**。
规则见 `references/06-命相同参与阳宅.md`。
